# BlogSpace – Module 04 CRUD Operations

A beginner-friendly blog application built with HTML, CSS, JavaScript, Node.js and Express.

## Features
- Create a blog post
- Read and display blog posts
- Update an existing blog post
- Delete a blog post
- Search blog posts by title or content
- Filter blog posts by category
- Store blog data in `data/blogs.json`

## Requirements
Install Node.js on your computer: https://nodejs.org/

## Run the project in VS Code
1. Extract the ZIP file.
2. Open the extracted `Blog_CRUD_Module04` folder in VS Code.
3. Open Terminal → New Terminal.
4. Run `npm install`.
5. Run `npm start`.
6. Open `http://localhost:3000` in your browser.

Keep the terminal running while using the website. Blog data is saved in `data/blogs.json`.

## GitHub upload
1. Create a new GitHub repository, for example `blog-crud-module-04`.
2. Upload the project files and folders (not just the ZIP).
3. Make sure `server.js`, `package.json`, `README.md`, `data` and `public` are in the repository.
4. Commit the files.

## Important deployment note
This project uses a Node.js/Express backend. GitHub Pages does not run Node.js servers, so a GitHub Pages URL will not make the full CRUD app work. Run it locally using the steps above, or deploy the Node.js project to a Node.js hosting service if a public live URL is required.
